# Naruto 5 Recomp - Windows x64

Execute `instalar.bat` e escolha a ISO e a pasta de instalação. Depois use o
atalho criado ou `jogar.bat`.

O pacote é autocontido: Zig, Python, SDL2/3, wgpu-native, `eerecomp.exe` e
`vurecomp.exe` estão em `toolchain\`. Nada é baixado. A ISO e o código gerado
do jogo não acompanham o pacote; o build é feito na sua máquina.

Detalhes em `README-WINDOWS.md` e `LEIA-ME.txt`.
